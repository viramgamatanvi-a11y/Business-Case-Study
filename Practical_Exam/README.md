=> Regional Sales Dashboard 

1. Overview
This dashboard analyzes regional sales performance, operational issues, and revenue loss due to cancellations and returns using the dataset “RegionalSales2025.csv”. SQL was used for data cleaning, filtering, and aggregation to ensure accurate and efficient analysis.

2. Key Insights
Sales Performance => 
	Total completed sales: ~$1.04M
	Total orders: 500
	This reflects strong overall performance with a high number of successful transactions.

Average Order Value (AOV) => 
	AOV: ~$2.78K
	Customers are making relatively high-value purchases, contributing positively to revenue.

Cancellations & Returns Impact => 
	Cancellations: 74 | Returns: 53
	Revenue loss: ~$368.91K
	Around 25% of orders are impacted, indicating a major area of concern.

3. Performance Analysis
Regional Performance => 
	South region leads in revenue
	North & West show stable performance
	Some regions show category-level underperformance

Category Trends => 
	Top categories: Sports, Electronics
	Moderate growth: Beauty, Home & Kitchen

Monthly Trend => 
	Sales show a decline after peak months, possibly due to seasonality or customer retention challenges.

4. Key Challenges => 
	High cancellation and return rates
	Declining sales trend
	Uneven regional and category performance
	Operational inefficiencies

5. Recommendations => 
	Improve return and cancellation processes
	Focus marketing on underperforming areas
	Use predictive analytics for demand forecasting
	Analyze customer behavior for better retention
	Introduce KPIs like CLV, Return Rate, and Conversion Rate

6. Conclusion => 
	The dashboard effectively highlights revenue drivers and operational issues. SQL-based preprocessing ensures reliable insights, helping businesses make informed and strategic decisions.
